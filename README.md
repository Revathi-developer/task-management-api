
# Task Management System

A full-stack task management application built with Django REST Framework
and React. Users can securely log in, create and manage tasks, search and
filter tasks, update task status, and manage their profile.

## Tech Stack

### Backend
- Python
- Django
- Django REST Framework
- JWT Authentication
- PostgreSQL

### Frontend
- React
- Vite
- JavaScript
- CSS

### Features
- User registration and authentication
- JWT access and refresh tokens
- Create, update, delete and view tasks
- Task status management
- Search and filtering
- Ordering
- Pagination
- User profile
- Change password
- Protected routes
- Custom permissions
